# Описание
Наш проект решает проблему оценки мнения посетителей выставок и галерей об их оформлении с помощью модели, имитирующей прохождение человека по картинной галерее для демонстрации идеи машинного анализа эмоций. Он имеет такие свойства как модульность, малая требовательность в обслуживании, в перспективе увеличение интереса пользователей.
# Разработка
Мы делаем ПК приложение.
Стек технологий: Pycharm - разработка, Figma - моделирование идей, Yandex Claud - хостинг бд
С пременением языка программирования Python, Yandex Claud - выгрузка баз данных на хостинг, библиотеки PyQt, PyGame, boto3, FER и OpenCV (для анализа эмоций и обработке изображений)
